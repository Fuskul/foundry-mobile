# Foundry Mobile — установка и первый запуск

Инструкция для человека, который не занимается разработкой. Ничего компилировать не нужно.

## Что вы получаете

- **Модуль для Foundry** (`fvtt-mobile-bridge`) — ставится в Foundry как обычный модуль.
- **Мобильную веб-версию** — открывается на телефоне сразу, без установки.
- **Android-приложение (APK)** — то же самое, но отдельным приложением; собирается автоматически на GitHub.

## Шаг 1. Поставить модуль

1. Распакуйте `fvtt-mobile-bridge.zip` в папку `Data/modules` вашего Foundry.
   Должно получиться `Data/modules/fvtt-mobile-bridge/module.json`.
2. **Перезапустите Foundry** — новые модули он видит только при старте.
3. Зайдите в мир → «Управление модулями» → включите **Mobile Bridge (Foundry Mobile)**.
4. Перезагрузите мир.

## Шаг 2. Открыть на телефоне

В окне игры нажмите значок телефона в панели инструментов слева
(или «Настройки» → «Мобильное приложение»). Появится QR-код и два адреса:

- **Мобильная веб-версия** — отсканируйте QR телефоном, и приложение откроется в браузере.
- **Адрес сервера** — его нужно ввести в Android-приложении.

Телефон должен видеть сервер: либо он в той же Wi-Fi сети, либо у Foundry есть внешний адрес.

## Шаг 3. Войти

В приложении:

1. Введите адрес сервера (например `192.168.1.50:30000`) → «Проверить сервер».
2. Выберите своего игрока и введите пароль (если он есть) → «Войти».

## Как это работает (важно)

Приложение не пересчитывает правила WFRP4e само. Оно просит модуль, который работает
**в браузере у Мастера**, подготовить лист и кинуть кубы настоящим движком системы.
Поэтому:

> Хотя бы один обычный клиент Foundry (обычно Мастер) должен быть в игре,
> иначе приложение покажет «Модуль-мост не найден».

Зато броски получаются полностью правильные: УУ, криты, промахи, локации попадания,
Преимущество, эффекты талантов — всё как на компьютере, и карточка появляется в общем чате.

## Настройки модуля (у Мастера)

| Настройка | Что делает |
| --- | --- |
| Включить мост | Полностью выключает работу с телефонами |
| Разрешить броски из приложения | Только чтение листа, без кубов |
| Требовать владение персонажем | Если выключить, наблюдатели тоже увидят лист |
| Этот клиент обслуживает телефоны | Обычно «автоматически»; нужно только для отладки |
| Подробный лог | Пишет каждый запрос в консоль браузера (F12) |

## Если что-то не работает

1. Откройте в приложении «Ещё» → «Журнал подключения» → «Скопировать журнал».
2. В браузере Мастера нажмите F12 и посмотрите строки `[MobileBridge]`.

Частые причины:

- **Не открывается адрес** — телефон в другой сети, или Foundry слушает только localhost.
- **«Модуль-мост не найден»** — у Мастера не включён модуль, или он не в игре.
- **Пустой список игроков** — введён адрес с `/game` на конце; нужен адрес сервера без пути.

Отдельное приложение собирается автоматически на GitHub — Android Studio не нужна.
